# 艺术卡片 · AI 分析 Agent 部署说明(约 15 分钟)

整条链:App「🤖 AI深析」按钮 → Cloudflare Worker(免费,替你保管密钥)→ DeepSeek → 返回 10 条公约 + 观众寄语。

## 第一步:拿 DeepSeek API Key(约 5 分钟)

1. 打开 https://platform.deepseek.com ,手机号注册
2. 左侧「充值」:充 10 元足够用很久(一次分析约 1 分钱)
3. 左侧「API Keys」→「创建 API Key」,复制保存(形如 `sk-xxxx`,只显示一次)

## 第二步:部署 Cloudflare Worker(约 8 分钟)

1. 打开 https://dash.cloudflare.com ,注册/登录(免费套餐即可)
2. 左侧 Workers & Pages →「创建」→「创建 Worker」,名字填 `art-agent` →「部署」
3. 点「编辑代码」,把本目录 `worker.js` 的全部内容粘贴进去,覆盖原有代码 →「部署」
4. 回到该 Worker 的「设置」→「变量和机密」→「添加」:
   - 类型选 **机密(Secret)**,名称填 `DEEPSEEK_KEY`,值粘贴第一步的 sk-xxxx → 保存
5. 记下 Worker 地址,形如 `https://art-agent.你的子域.workers.dev`

## 第三步:告诉 App 地址(1 分钟,二选一)

- **方式 A(推荐)**:把地址发给 Claude,由我写进 `index.html` 的 `AGENT_URL` 常量并发布
- **方式 B(自己测试)**:在 App 页面的浏览器控制台执行
  `localStorage.setItem('ac_agent_url','https://art-agent.xxx.workers.dev')` 后刷新

配置完成后,谱系页选中 2 件以上作品,「🤖 AI深析」按钮就会出现。

## 注意

- workers.dev 域名在国内部分网络不稳;如果不通,在 Cloudflare 里给 Worker 绑一个自定义域名(需要一个你自己的域名)会稳很多。
- 密钥只存在 Worker 的机密变量里,代码仓库和前端都没有它,可以放心开源。
- Worker 已限制:只接受本 App 域名的请求、每次最多 8 件作品。
